# 《NABO 牌桌》美术规格

本文件是美术制作的唯一依据。所有素材放在 `nabo-table/art/` 下，不要修改仓库其他目录。玩法见 [DESIGN.md](DESIGN.md)。

## 1. 游戏是什么

两个人传着一台徽章玩的牌桌合集：21 点和大话骰。NABO 是**荷官兼裁判**，站在牌桌后面，负责洗牌、发牌、摇盅、喊"开！"、宣布赢家。NABO 不参与对局。

## 2. 硬件约束（必须遵守）

- 屏幕 **240×320 竖屏**，RGB565。精灵内部不要用大面积细微渐变，会出现色带。
- NABO 有两种显示尺寸：
  - **大图约 150 px 高**：封面、交接屏、整场结束；
  - **小图约 72 px 高**：对局中屏幕顶部的荷官位。
  同一套帧用渲染脚本的 `--scale` 出两种尺寸，**两种尺寸都要能认出 NABO、看清表情**。
- 每个精灵 **不超过 32 色**，边缘可以有半透明抗锯齿。
- 背景是牌桌绒布色（见第 8 节），**NABO 必须在绒布色上一眼认出来**。
- 扑克牌牌面（点数、花色）和骰子点数由程序绘制，**不需要画**。

## 3. NABO 造型

角色就是 NABO。**身份（脸、眼睛、镜框、发型、白帽和帽标、比例）以 `../ai-passport-nabo-xiaozhi/docs/images/nabo-idle.png` 为准，不能改。** 服装可以换成荷官装。

**已定稿：`art/design/option_a.png`（梅紫经典：梅紫 V 领马甲、象牙白衬衫、黄铜领结）。** 之后所有动作都从这张定稿出发：起始图沿用它的身份和服装，再图生视频（见第 4 节）。

- **半身构图**：NABO 站在牌桌后面，桌沿挡住腰部以下，**不需要腿**。
- 72 px 下仍能认出是 NABO 最重要。太细碎的细节会糊，可以适当简化，但不能改变 NABO 的形象。
- 外描边用深色（各部位固有色的深色），不要白色贴纸式描边。

画风：沿用深潜，干净的 2D 卡通，**平涂加两阶赛璐珞阴影**，粗描边，不要软 3D 渲染。

## 4. 制作方式：起始图 → 图生视频 → 处理成帧

（2026-10-18 起改用这套流程，骨骼拼接方案作废，动作更自然。）

1. 为每组动作出一张起始图（持牌、持骰盅、空手），身份和服装与定稿一致。
2. 用起始图生成视频，每条从起始姿势开始、回到起始姿势结束。
3. 交回原视频后处理：稳像、抠掉背景、裁成 256×256、对齐锚点、抽帧、限色。

镜头清单和每条的要求见 [`art/reference/SHOT_LIST.md`](art/reference/SHOT_LIST.md)。

## 5. 画布与朝向

- 每帧 **256×256 RGBA PNG**，透明背景。
- **锚点固定在 (128,224)，对准桌沿线的中点**（角色身体在桌沿上方，桌沿以下透明）。所有帧、所有动作锚点一致，否则播放时会抖。
- 朝向：**正面朝向观众**。**不能左右镜像**：帽子上的 NABO 字样会反过来，所以指向左、右各做一条。
- 桌面本身由程序绘制，**不要画桌子**；桌沿线以下的手臂部分直接裁掉即可。

## 6. 动作清单

帧率统一 12 fps。"必需"的先做。帧数是游戏里的目标，从视频里抽帧得到；完整镜头清单和优先级以 `art/reference/SHOT_LIST.md` 为准。

| 动作 | 目录 | 帧数 | 循环 | 必需 | 用在哪里 / 说明 |
|---|---|---|---|---|---|
| 待机 | `idle/` | 8 | 是 | ✅ | 对局中等玩家操作时。轻微呼吸、眨眼一次，飘动部件轻摆 |
| 洗牌 | `shuffle/` | 8 | 是 | ✅ | 封面 21 点入口、每局开始。双手对洗（riffle），牌在两手间落下 |
| 发牌 | `deal/` | 4 | 否 | ✅ | 每发一张牌播放一次。手腕一甩把牌推向观众，`events` 标出牌离手的帧 |
| 摇盅 | `shake/` | 6 | 是 | ✅ | 封面大话骰入口、每局摇骰。双手握骰盅上下快速摇，身体跟着晃 |
| 扣盅 | `slam/` | 3 | 否 | ✅ | 摇完把骰盅扣在桌上，带一点挤压回弹；`events` 标出落桌帧 |
| 捂眼进入 | `cover_in/` | 3 | 否 | ✅ | 交接屏出现时，双手抬起捂住眼睛 |
| 捂眼循环 | `cover/` | 4 | 是 | ✅ | 交接屏等待时，捂着眼轻轻左右晃，表示"我没看" |
| 开！ | `open/` | 5 | 否 | ✅ | 开牌 / 开盅时：预备、单手高举、张大嘴喊；`events` 标出喊出的帧 |
| 指向赢家 | `point_l/`、`point_r/` | 4 | 否 | ✅ | 一局结束，伸手指向赢家那一侧，最后一帧停住；左右各一条，不镜像 |
| 惊讶 | `surprise/` | 4 | 否 | ✅ | 爆牌、开中、大逆转时。弹起、眼睛瞪大、嘴成 O 形，最后一帧可接回 idle |
| 夺冠 | `trophy/` | 6 | 是 | ✅ | 整场结束：双手举奖杯，开心表情 |
| 平局 | `shrug/` | 4 | 否 | 推荐 | 平局时耸肩摊手 |
| 封面招呼 | `wave/` | 6 | 否 | 可选 | 进入封面时挥手 |

动画原则：要有**预备动作、跟随动作和缓入缓出**。飘动部件比身体慢半拍。不要线性插值。所有单次动作的最后一帧都要能自然接回 `idle` 第 1 帧（`point` 和 `trophy` 除外）。

## 7. 道具

道具既挂在 NABO 手上播放动画，也会被程序单独使用，所以要**单独导出**一份。

| 道具 | 目录 | 最终尺寸 | 说明 |
|---|---|---|---|
| 牌背 | `props/card_back.png` | 36×50 px | 一张扑克牌的背面，带 NABO 主题的小图案，圆角，深色描边。程序会大量重复绘制它 |
| 牌背大图 | `props/card_back_l.png` | 72×100 px | 同一设计的大尺寸版本，用于开牌动画 |
| 骰盅 | `props/cup.png` | 约 56 px 高 | 扣着的骰盅，正面视角。程序会用它做掀盖动画（整体上移） |
| 奖杯 | `props/trophy.png` | 约 40 px 高 | 夺冠画面 |

道具画布按最终尺寸的 4 倍出图，并在 manifest 里写明目标尺寸。

## 8. 配色

给出 `palette/table.json`，十六进制 RGB 并附 RGB565 值。下面是起点，可以微调，但要保证 NABO 在绒布上醒目：

```json
{
  "felt":        "#0E3B36",
  "felt_dark":   "#082623",
  "rim":         "#3A2418",
  "brass":       "#C9A24A",
  "player1":     "#FF8A3D",
  "player2":     "#3DB8FF",
  "card_face":   "#F4F1E8",
  "ink":         "#14100E"
}
```

- 玩家 1 是暖色，玩家 2 是冷色，界面会用它们区分两个人；NABO 本身**避免大面积使用这两种颜色**，免得被误认为站在某一方。
- 牌背主色要和绒布拉开明度，堆在桌上时能数清张数。

## 9. 交付结构

```
nabo-table/art/
├── design/          造型方案、定稿
├── reference/       起始图 S1/S2/S3、镜头清单 SHOT_LIST.md、视频提示词
├── video/<批次>/source/   交回的原视频，原样保留
├── props/           牌背、骰盅、奖杯静态图
└── palette/table.json

处理成游戏帧由 ../tools/clip_to_sprites.py 完成（输出到 ../sprites/），
原型用的精灵条由 ../tools/build_proto_atlas.py 生成。
```

`manifest.json` 格式：

```json
{
  "canvas": [256, 256],
  "anchor": [128, 224],
  "fps": 12,
  "nabo_target_height_px": { "large": 150, "small": 72 },
  "facing": "front",
  "animations": {
    "idle": { "loop": true,  "frames": ["frames/idle/01.png", "..."] },
    "deal": { "loop": false, "frames": ["..."], "events": { "release": 3 } }
  },
  "props": {
    "card_back": { "target_px": [36, 50], "file": "props/card_back.png" }
  }
}
```

## 10. 验收清单

- [ ] 72 px 高时放在绒布色上，能认出 NABO、看清表情
- [ ] 每个循环动作首尾无缝
- [ ] 所有帧锚点一致：叠在一起看，桌沿线不动
- [ ] 每个精灵不超过 32 色
- [ ] 没有任何帧是镜像出来的（帽标 NABO 字样方向正确）
- [ ] 外描边是深色，不是白色贴纸描边
- [ ] 牌背在 36×50 px 下清晰，堆叠时能数清张数
- [ ] 渲染脚本可以重新跑出全部帧，README 写明命令
- [ ] 只用自己绘制的素材，没有复制第三方图片
