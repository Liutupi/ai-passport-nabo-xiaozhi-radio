## 权威身份与制作方法

已确认参考：固件仓库的 `docs/images/nabo-idle.png`，使用左格睁眼状态。v2以该图作为身份依据，经内置图像生成工具制作共享基底，再分别编辑衣服；没有使用已否定的SVG脸部，也没有程序拼接或重画五官。

保留圆润脸颊、短小圆下巴、带上眼睑的温和椭圆眼、细圆框眼镜、蓬松深棕曲线发束、自然贴头的白帽与蓝色心电/NABO、短颈和窄肩。头发保留可供日后动作使用的发束，本次未制作运动。

先做原参考与A/B/C并排身份检查，再看150/72px。初次导出的小笑线过淡，已分别通过图像工具加深和加粗原闭口笑线，保留位置、长度和闭口表情；不是程序另画嘴。最终另由独立审核者实际看图确认三案身份统一，两档均可读出闭口笑。

生成原图及完整提示词在 `v2/sources/option_*_generated.png`、`v2/prompt_*.txt` 和 `v2/prompts.json`；笑线修订前源图也有备份。程序仅执行透明区杂点清理、共同平涂色板、缩放和设计板排版。最终采用每材质基色加两阶离散阴影，不保留柔和3D渐变或白色贴纸外描边。

## 版本与重建

已否定v1完整保存在 `archive/20261018_v1_identity_rejected/`，包括旧三张PNG、旧SVG和旧导出脚本，不作为v2权威参考。根目录的旧重建入口已切换至v2，避免误运行后恢复失败稿。
