# 《NABO FM》电台版设计（M0 草案 v2）

> 状态：设计草案，2026-10-19。美术已可开工（见 ART_BRIEF.md）；界面原型、固件改动还没开始。
> v2 变化：定位改为面向社区所有用户的“最好的电台”；加入竞品分析、全社区电台合集、小智语音点歌（苹果手机可用）、在线电台表。

## 1. 一句话

把工牌变成一台小收音机：上半屏是 NABO 坐在深夜直播间当 DJ，下半屏是琥珀色调频刻度，上下键像拧旋钮一样扫台。**它是社区里唯一一台会听话、会动的电台**：内置小智，说一句“放广州的交通台”就换台；台全，声音稳，界面精致。

面向所有 AI Passport 用户发布到玩法社区，不只是自用。

## 3. 版本归属

- 新仓库 `ai-passport-nabo-xiaozhi-radio`，从牌桌版 v1.6 分出。
- **只做电台**：移除牌桌和跳一跳，应用分区和资源分区全部给电台。
- **保留设置页**（音量、亮度、Wi-Fi 配网、自动熄屏、关于）。
- 分区表、NVS 键和板型身份 `ai-passport-nabo` 保持兼容，可以用 upgrade 模式和其他版本互相切换。另出一个从 `0x0` 刷写的合并镜像，给没装过 NABO 固件的社区用户用网页刷机工具安装。

## 4. 电台资源（最重要）

### 4.1 全社区合集

- 2026-10-19 已合并 **1,142 个台**（`catalog/stations.json`）：蜻蜓网页公开电台页 1,086 台（31 个省 + 网络台，带热度和类型）、港新马 49 台、其他 7 台；魏宝辉 334 个蜻蜓台和我们旧表 47 台都已被覆盖。旧表里“中国之声”的编号其实已是河北“欢乐调频”，说明必须以抓取结果为准。
- 合并以下来源，去重后实测筛选：
  - 我们自己的 47 台（来自 Tab5）；
  - 魏宝辉 345 台（只取电台名和地址这类公开信息，不用其代码）；
  - 港新马 49 台（MIT，注明出处）；
  - 央广 / 云听的直播频道（多为 HLS）；
  - 公开电台数据库 Radio Browser 里的华语台和常听的国外台（社区共建、公开数据）。
- 每个台带：名称、地址、省份 / 城市、类型（新闻 / 音乐 / 交通 / 文艺 / 戏曲 / 方言…）、编码、码率、来源。
- 致谢页列出所有来源作者。

### 4.2 在线电台表（自动维护）

- 仓库里放一个检测脚本，用 GitHub Actions **每天**把全部电台试连一遍：HTTP 200、持续供流 8 秒、能连续解出合法帧。结果生成压缩的电台表，发布到仓库。
- 工牌联网后每周取一次最新电台表（几十 KB），失效的台自动下架，新台自动出现，**用户不用重新刷固件**。取不到就用固件内置的那份。
- 这一点社区里没有任何一款做到：其他电台都是写死在固件里，台挂了只能等作者发新版。

### 4.3 本地电台

- 联网后按 IP 判断所在城市，刻度上第一个波段就是“本地”（像“城市之声”）。也能在设置里手动改城市。
- 拼音首字母搜台（城市或台名，如 `GZJT` → 广州交通）。

### 4.4 格式支持

- MP3（大多数国内台）、AAC（港澳、马来西亚和部分国外台）、HLS（央广 / 云听）。
- 小智固件**本来就依赖乐鑫 `esp_audio_codec` 2.5**（Opus 用它），其中带 MP3 / AAC 解码器，社区两款电台已在 C3 上跑通。新音频链路优先用它；第一步先沿用旧版 Helix MP3 作为可编译的起点，量出空间后再替换。
- 蜻蜓流的开头落在帧中间（实测偏移 183 字节），播放器必须先扫描帧头（旧版已处理）。
- 能读到 ICY 曲目信息的台（港新马、很多国外音乐台）显示**正在播放的歌名**。

## 5. 界面

**外观定稿（2026-10-19）**：午夜琥珀配色 + 霞鹜文楷（台名、字标）+ 思源黑体（界面小字），色表见 `art/palette/radio_final.json`。固件按这两款字体生成 4-bit 字库子集；台名用的文楷字库要覆盖全部电台名用字。

布局见 `art/reference/ui_mockup_240x320.png` 和 `layout_annotated_3x.png`。

### 5.1 播放页（主页面）

|---|---|---|

| 调频刻度 | 222–282 | 琥珀色刻度尺，红色指针固定在中间，刻度带着电台标记左右滑动；波段依次为 **本地 / 收藏 / 新闻 / 音乐 / 交通 / 文艺 / 各省 / 港澳台 / 海外**，段上写波段名；收藏的台标记上方有小心形 |

### 5.2 电台列表页

- 顶部一排波段标签，当前高亮。
- 下面一屏 6 行电台，当前播放的台有小喇叭，收藏的有 ♥，连不上的灰掉。
- 列表第一行是“搜索”（拼音首字母），第二行是“最近听过”（10 台）。
- 标题栏左边是 24 px 的 NABO 戴耳机头像。

### 5.3 闲置时钟

- 播放中 1 分钟无操作，屏幕变暗成**夜间时钟**：大号时间 + 台名 + NABO 小头像随音乐轻点头；按任意键只唤醒，不触发功能。（“城市之声”有大时钟，港新马有熄屏继续播，我们两样都给。）

### 5.4 快捷面板（底部弹出）

定时关闭（关 / 15 / 30 / 60 / 90 分钟，到点前 1 分钟渐弱）、静电噪声音效开关、响度均衡开关、检查电台表更新。

## 6. 交互

按键：右侧 ▲、▼、OK。左侧电源键固件读不到。全局约定不变：**双击 ▲ 返回上一级，长按 ▲ 回小智**。

### 播放页

| 操作 | 作用 |
|---|---|
| ▼ 单击 | 下一台：指针滑到下一个标记 |
| ▲ 单击 | 上一台 |
| 按住 ▼ | 连续扫台，越按越快，松手停在最近的台；跨波段时刻度上闪出新波段名 |
| OK 单击 | 播放 / 暂停 |
| OK 双击 | 收藏 / 取消收藏当前台（NABO 比心） |
| OK 长按 | 菜单：电台列表、拼音搜台、定时关闭、沙沙声、设置 |
| 说“小智…” | 语音点台、点歌（见第 8 节） |

> 2026-10-19 原型调整：原先“OK 双击开列表、长按 ▼ 开面板”与“按住 ▼ 快速扫台”冲突（长按 ▲ 已被全局占用为回小智），改为 OK 双击收藏、OK 长按菜单。

扫台手感：

- 按键立刻有反馈：指针 180 ms 缓出滑到下一个标记，旋钮跟着转，NABO 切到“调台”动作。
- **停手 500 ms 后才真正连接**，连按十下只连最后一个台。
- 换台和连接期间播放很轻的收音机沙沙声（-24 dB，可关），节目一出声就淡出。
- ▲ 也是返回键：单击要等双击判定（约 250 ms）。为了扫台不拖手，▲ 单击时指针先动；如果紧接着第二下构成双击，就把指针退回原位并返回。（待实机试手感。）

### 列表页

▲ / ▼ 移动（按住 ▼ 连续下移）；OK 单击播放并回到播放页；OK 双击收藏；OK 长按切到下一个波段；双击 ▲ 返回播放页。

### 开关习惯

- 记住上次的电台；开机进入电台页定位到它，**关机时正在播的话联网后自动续播**，否则按 OK 才播。
- 电台播放时可以回到小智主页，声音继续。

## 7. NABO 的状态

| 电台状态 | NABO 动作 |
|---|---|
| 打开电台页 | `wave` 招手（一次）→ `idle_off` |
| 停止 / 暂停 | `phones_off` 摘耳机 → `idle_off` |
| 按 OK 播放 | `phones_on` 戴耳机 → `tune` |
| 换台 / 连接 / 缓冲 | `tune` 拧旋钮 |
| 播放：音乐类台、点歌 | `groove` 点头（速度随电平），和 `sing` 交替 |
| 播放：新闻 / 谈话类台 | `listen` |
| 播放中每 60–120 秒 | 随机插一次 `sip` 喝咖啡 |
| 收藏 | `love` 比心 |
| 连不上 | `oops` 哎呀 → `idle_off` |
| 没有 Wi-Fi | `search` 找信号 |
| 定时关闭最后 1 分钟 | `doze` 打瞌睡（程序加 Zzz） → 时间到 `phones_off` |

## 8. 小智语音和点歌（苹果、安卓都能用）

### 8.1 语音控制电台（第一期就做）

固件给小智开放一组设备工具（MCP），小智听懂后直接调用：

| 你说 | 工具 |
|---|---|
| “放广州交通台” / “来个音乐台” / “换山东的” | `self.radio.search` + `self.radio.play` |
| “下一台” / “随便来一个” | `self.radio.next` / `self.radio.random` |
| “暂停” / “继续” / “声音大一点” | `self.radio.pause` / `resume` / `set_volume` |
| “现在放的什么？” | `self.radio.now_playing`（台名、城市、曲目） |
| “收藏这个台” / “半小时后关掉” | `self.radio.favorite` / `self.radio.sleep_timer` |

说话时电台自动压低到 20%，小智答完恢复。这是社区里其他电台没有的：魏宝辉那款要在局域网里另开一个 AI 客户端；我们开箱就能说。

### 8.2 点歌：接入音乐 MCP（第二期）

苹果手机用不了 DLNA 投放，点歌走小智：

```
你：“小智，来首周杰伦的晴天”
  → 小智云端的大模型调用你接入的“音乐 MCP”搜歌、拿到播放地址
  → 再调用工牌的 self.radio.play_url(地址, 歌名, 歌手)
  → 工牌播放，NABO 跟唱，屏幕显示歌名
```

- 工牌固件只提供通用的 `self.radio.play_url`（以及播放列表：`queue_add` / `next` / `clear`），**不内置任何音乐平台**。用户在 xiaozhi.me 的智能体里接入自己选的音乐 MCP。
- 网易云的情况：
  - **官方**：2026 年 3 月网易云开放平台上线（`ncm-cli` 和官方 Skills），需要实名个人开发者申请 appId 和私钥，每个人自己申请；目前没看到“给第三方设备拿播放地址”的明确说明，要实测。
  - **非官方接口**：社区已有不少“小智 + 网易云 MCP”项目，但它们依赖非官方接口，**不适合打包进一个面向所有人的社区固件**（版权和账号风险）。
- 所以对社区：提供通用接口 + 一份接入说明（支持官方开放平台的方式优先），用户自己接；对你本人：可以先用你自己的开放平台账号做一个参考实现，跑通后再写进说明。
- 风险：大模型转述很长的签名地址可能抄错。参考实现让 MCP 返回短地址（自己的服务器转一下），待实测。
- 音质：播放地址是 MP3 128k / 320k 都能放；FLAC 看 `esp_audio_codec` 在 C3 上的内存，待测。

### 8.3 DLNA 投放（安卓用户的附加功能，第三期）

- 工牌在局域网里扮演 DLNA 音箱“NABO FM”，安卓版网易云（设置 → 连接DLNA设备）、QQ 音乐等可以直接投歌过来。苹果版网易云没有这个选项。

## 9. 音质和稳定性

读旧版代码发现的问题和改法：

| 问题 | 旧版现状 | 改法 |
|---|---|---|
| 缓冲太小 | 解码后 PCM 只缓冲约 0.4 秒 | **缓冲压缩数据**：32 KB 约 4 秒（64 kbps），攒够 1.5 秒开播 |
| 重采样粗糙 | 线性插值把 48 kHz 降到 16 kHz，没有低通 | 实测蜻蜓 64k 流是 **48 kHz 立体声 MP3**：电台模式 I2S 切 24 kHz，正好 2:1，用整数半带 FIR 抽取，频宽 8 → 约 11 kHz，算力比通用重采样还省 |
| 爆音 | 开始、换台、暂停直接切 | 40 ms 淡入、60 ms 淡出 |
| 断线 | 丢掉全部数据，2→30 秒退避重连 | 先放完缓冲里的几秒，同时立刻重连 |
| 破音 | 满幅输出 | 2 dB 余量 + 软限幅 + 120 Hz 高通保护小喇叭 |
| 台与台音量不一 | 无 | **慢速响度均衡**（魏宝辉那款有，我们也要有，可关） |

验收指标：稳定 Wi-Fi 下连续播 1 小时卡顿 0 次；换台到出声中位数 ≤ 2 秒；空闲堆 ≥ 60 KB；来回切台 50 次无重启。

## 10. 离线也有声音

没网时不至于哑巴：内置几段离线助眠声（雨声、海浪、炉火、白噪音 / 粉红噪音 / 棕噪音），程序合成或短循环采样，作为刻度最右边的“离线”波段。（“听见”有这项，我们也给。）

## 11. 分期

- **第一期**：新界面、刻度扫台、NABO DJ 动画、全社区合集 500+ 台、在线电台表、本地电台和拼音搜索、最近听过、收藏、定时关闭、夜间时钟、第 9 节的音质改进、MP3 + AAC、语音控制电台、设置页。
- **第二期**：通用点歌接口 `play_url` 和播放列表、网易云接入说明和参考实现、HLS（央广）、ICY 曲目显示、离线助眠声。
- **第三期**：DLNA 投放、手机网页管理（增删自定义电台）、闹钟电台、播客。

## 12. 技术预算

- 应用分区（2026-10-19 实测首个电台版构建）：应用 3,334,112 字节，**剩 776 KB**（牌桌版只剩 150 KB）。`esp_audio_codec` 的 MP3/AAC 代码体积待接入后再量。
- 资源分区（3 MB）：现在用了 1.32 MB，**剩 1.82 MB**。计划放入 NABO DJ 动画约 0.8–1.2 MB、完整中文字库约 250 KB、内置电台表约 60 KB；离线助眠声按剩余空间定。
- 内存：播放时同时要有 TLS（约 17 KB 连续块）、解码器（MP3 约 24 KB，AAC 更多）、32 KB 压缩缓冲、小智的对话通道。小智对话和电台同时在线的内存是最大难点，原型阶段先实测。
- 帧率：舞台区 15–20 fps（动画本身 12 fps），刻度滑动时 30 fps。
