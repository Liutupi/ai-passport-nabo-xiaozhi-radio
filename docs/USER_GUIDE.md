# NABO FM v1.0.1 使用指南

v1.0.1 为部分验收的体验更新。台 26 约 3 分钟短测、2 轮主页往返及用户当前短时听感已确认；三台各 600 秒、20 次切台与完整连续语音尚未完成。安装范围和限制见 [发行说明](RELEASE_FM_v1.0.1.md)。

## 先安装与配网

1. 适用 FoloToy AI Passport（ESP32-C3 / 8 MB）。社区完整 BIN 从 `0x0` 写入，会清空已保存的 Wi-Fi、激活和 NVS 设置；保留数据请先读 [刷写说明](FLASHING.md)。本组合没有在空白设备重新完整首装验收。
2. 首次没有网络记录时会进入配网。已使用的工牌换网，可在 NABO 主页按下键 → 工具 → 更多设置 → 添加网络。
3. 手机连接屏幕显示的 `Xiaozhi-XXXX` 热点，浏览器打开 `http://192.168.4.1`。选择自己的 **2.4 GHz Wi-Fi**，输入密码，点“连接”。
4. 网页显示“配置成功”且工牌联网后，按工牌 OK 返回；连接失败时核对密码并重试。若提示小智激活或绑定，按屏幕指引完成自己的设备绑定。
5. NABO 主页按下键 → 工具 → 网络电台；上下换台，OK 播放/暂停。OK 在 NABO 主页用于开始语音对话。

## 播放页的三个按键

| 操作 | 功能 |
|---|---|
| ▲ / ▼ 单击 | 上一台 / 下一台；停手 500 ms 再连流 |
| 按住 ▼ | 加速扫台 |
| OK 单击 | 播放 / 暂停；有 250 ms 双击判定时间 |
| OK 双击 | 收藏 / 取消收藏，最多 128 台 |
| OK 长按 | 菜单：电台列表、收藏列表、拼音搜台、定时、沙沙声、响度均衡、待机时钟、本地地区、设置 |
| ▲ 双击 | 返回上一级；上键第一下的移动会撤回 |
| ▲ 长按 | 停止电台并回小智 |

列表里 ▲▼ 选台、OK 播放，双击 OK 收藏，长按 OK 切换波段；每屏七台。拼音搜索中 ▲▼ 选字母，OK 输入；`<` 删除，`OK` 跳到匹配结果，再选台。支持拼音首字母，如 GZJT。

## 收藏、时钟与定时

定时关闭可选关 / 15 / 30 / 60 / 90 分钟，最后一分钟声音逐步变小。电台菜单“待机时钟”可选 1、3、5、10 分钟或“关闭待机”；启用后，无操作到时进入北京时间小钟，背光降到不高于 15%，任意键第一次只唤醒。关闭电台待机时钟与系统设置里的休眠是两项独立设置。

从电台菜单打开设置时继续播放；从播放器双击上键回工具也保留当前播放。长按上键回小智时停止并释放电台资源，再恢复语音服务。收藏、最近十台、地区、均衡、待机时长和沙沙声开关保留在 NVS；记住播放状态后重新开机可进入电台续播。直接断电前尚未提交的设置可能丢失。

## 语音与使用边界

在小智主页可说“打开电台 / 网络电台 / 收音机”。设备工具还可搜索并播放指定台、随机、设音量和定时。**当前播放模式暂停小智语音，不能边播边说话控制。** 长按上键回主页后再发语音指令。本版没有开启本地唤醒词；本轮没有完成恢复后的完整连续对话验收。

本地地区需要手动选择，默认“全国”。台表来自 2026-10-19 设计数据，不自动在线更新。部分源可能失效或超时；AAC/HE-AAC、全部台和任意网络环境的长时流畅度未验收，1,105 不代表当前全部可播。

左侧电源键由硬件处理，固件读不到它的短按。系统音量、亮度、麦克风、Wi-Fi 和休眠沿用 NABO 设置页。
