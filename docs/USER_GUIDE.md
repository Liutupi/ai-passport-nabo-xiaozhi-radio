# NABO FM v1.0.0 使用指南

首次配网、激活沿用小智流程。OK 在 NABO 主页开始对话，下键进入工具菜单，选择网络电台。本版为首版体验固件，实测范围和限制见 RELEASE_FM_v1.0.0.md。

| 电台播放页操作 | 功能 |
|---|---|
| ▲ / ▼ 单击 | 上一台 / 下一台；停手 500 ms 再连流 |
| 按住 ▼ | 加速扫台 |
| OK 单击 | 播放 / 暂停，单击有 250 ms 双击判定时间 |
| OK 双击 | 收藏 / 取消收藏，最多 128 台 |
| OK 长按 | 菜单：电台列表、收藏列表、搜索、定时、沙沙声、响度均衡、待机时钟、本地地区、设置 |
| ▲ 双击 | 返回上一级；上键第一下的移动会撤回 |
| ▲ 长按 | 停止电台并回小智 |

列表里 ▲▼ 选台、OK 播放，双击 OK 收藏，长按 OK 切换波段。列表每屏七台。拼音搜索中 ▲▼ 选字母，OK 输入；`<` 删除，`OK` 跳到匹配结果，再选台。支持拼音首字母，如 GZJT。

定时关闭可选关 / 15 / 30 / 60 / 90 分钟，最后一分钟声音逐步变小。电台菜单“待机时钟”可选 1、3、5、10 分钟或“关闭待机”；启用后，无操作到时进入时钟，背光降到不高于 15%，任意键第一次只唤醒。关闭待机不会自动进入时钟。此设置与系统设置里的休眠不同。

从电台菜单打开设置时继续播放；从播放器双击上键回工具也保留当前播放，长按上键回小智时停止并释放电台资源。收藏、最近十台、地区、均衡、待机时长和沙沙声开关保留在 NVS；记住播放状态后重新开机可进入电台续播。直接断电前尚未提交的设置可能丢失。

在小智主页可说“打开电台 / 网络电台 / 收音机”。通过设备工具还可搜索并播放指定台、随机、设音量和定时。**当前播放模式暂停小智，不能边播边说话控制。** 长按上键回主页后再发语音指令。本版没有开启本地唤醒词。

本地地区目前需要手动选择；默认“全国”。台表来自 2026-10-19 设计数据；自动更新和 IP 定位尚未接入。失效流、AAC 兼容性仍需实机验证，不保证所有 1,105 台当前可播。

左侧电源键由硬件处理，固件读不到它的短按。系统音量、亮度、麦克风、Wi-Fi 和休眠沿用原 NABO 设置页。
