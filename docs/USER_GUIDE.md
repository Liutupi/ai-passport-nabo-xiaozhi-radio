# 使用指南

## 配网与激活

首次启动按照工牌屏幕提示，用手机完成 2.4 GHz Wi-Fi 配网。若进入热点配网，连接屏幕显示的 `Xiaozhi-xxxx`，访问 `http://192.168.4.1`。随后在 <https://xiaozhi.me> 添加设备并输入屏幕上的激活码。热点名由每块设备生成，不能照抄示例尾号。

已有本定制固件且已激活的设备，通过应用升级保留配置。OK 开始/结束小智对话；本版未启用本地唤醒词。

## 常用按键

| 场景 | OK | 上键 | 下键 |
|---|---|---|---|
| NABO 待机 | 开始/结束对话 | 设备状态 | 工具菜单 |
| 小智对话 | 开始/结束对话 | 调高音量 | 调低音量 |
| 跳一跳 | 按住蓄力，松开起跳 | 回工具 | 切换 NABO / 经典棋子；长按重新开始 |
| NABO 牌桌 | 确认（松开时生效）；按住 2 秒暂停 | 向上选 / 加；按住连续 | 向下选 / 减；按住连续 |
| 其他菜单 | 选中/执行 | 按页面提示 | 按页面提示 |

**双击右侧上键返回上一级，单击保持当前页面原功能；长按上键直接回 NABO / 小智。** 在设置编辑中，第一次双击结束编辑，下一次双击返回工具。左侧电源键由硬件处理，固件读不到它的短按；仍使用长按开关机。

## 语音打开

在小智主页按 OK 开始对话，说：

- “打开牌桌”“打开大话骰”或“打开二十一点”。
- “打开跳一跳”。
- “打开谁是卧底”。
- “打开设置”或“打开工具”。

支持“请帮我打开牌桌”“玩大话骰”等明确指令。语音识别仍需要服务器和网络；设备收到识别结果后直接打开程序。“不要打开牌桌”“如何打开大话骰”等否定/询问句不会被本地规则直接执行。一次请只打开一个程序。

进入本地程序后小智暂停。长按上键回到小智，再按 OK 继续对话并打开下一项。

开机后不必等小智联网：还在找 Wi-Fi 或等待配网时，下键进工具菜单就能玩，退出后小智接着启动。

## 跳一跳

按住 OK，NABO 屈膝蓄力；松开后摆臂蹬地起跳。落地会屈膝缓冲并站稳。跳空时掉在平台旁边，撑地跌坐后结束，人物保留在画面里。

落地和镜头移动期间就可以开始下一次蓄力，无需等镜头停稳。提前松开也会保留实际按住时间。正中连击依次加 2、4、6 分，最高分保存到设备。

平台包括医院、书房、播客、木鱼、咖啡和靶心。下键可切换经典棋子，长按下键重新开始。

## 谁是卧底（v1.6.0 新增）

在工具菜单打开「NABO 牌桌」，封面选择「谁是卧底」；也可以在小智主页说“打开谁是卧底”直达人数设置。上/下键选择 **3–8 人**，OK 发词，人数会独立保存。3–6 人有 1 个卧底，7–8 人有 2 个卧底。

1. 按屏幕顺序把工牌交给对应玩家。接过后按 OK 看自己的词，再按 OK 盖回并交给下一位；每人只知道自己的词，不直接知道身份。
2. 全员看完后，按屏幕提示的先手顺序轮流口头描述，避免直接说出词本身。词库有 264 组相近词，双方拿到同组的不同词。
3. 描述页选择投票，用上/下键选要出局的玩家，OK 后再确认一次；可取消返回。投票结果由同桌玩家讨论决定，再在工牌上输入，不是每人秘密按键计票。
4. 揭晓被投玩家的身份。卧底全部出局则平民胜；剩余卧底人数不少于平民人数则卧底胜，否则继续下一轮描述。
5. 忘词时，在描述页选「有人忘词」，选择对应玩家，按交接提示私密重看；不会重新发词。对局中按住 OK 2 秒可打开暂停菜单返回封面。

节奏回声已在本版移除，需要该玩法时请使用旧版本。

## NABO 牌桌

工具菜单第三项。21 点和大话骰由 2–4 个人传着一台工牌玩，NABO 是荷官。封面上下选「21 点」「大话骰」「谁是卧底」「N 人」或「抢 N / 罚 N」，OK 进入；「N 人」仅设置 21 点和大话骰，在 2 / 3 / 4 人之间切换，「抢 N / 罚 N」在 3 / 5 / 7 之间切换（21 点先赢满这么多局的人拿下整场，大话骰先被罚满这么多分的人输），两项都会记住。工牌按玩家 1 → 2 → 3 → 4 的顺序传，玩家 1–4 分别是橙、蓝、粉、绿色。在封面双击或长按上键退出。

**交接屏：** 每次换人，NABO 捂眼，屏幕写「请交给 玩家 N」，只显示公开信息。接过工牌的人按 OK 才看到自己的牌或骰子，操作完自动盖回。

**21 点：** 每人两张暗牌，轮流选「要牌」或「停牌」，所有人都停牌后一起开牌。A 记 1 或 11 自动取有利值，J/Q/K 记 10；超过 21 点爆牌，不爆的人里点数最高的赢，并列最高的都得一局；全部爆牌或所有人点数相同算平局。别人只能看到你有几张牌、是否已停牌。打到目标局数时如果有人并列领先，会继续加赛。

**大话骰：** 每人 5 颗骰子，按顺序叫「N 个 X」（全桌合计至少 N 颗 X），后叫的要更大：数量更多，或数量相同点数更大；也可以选「开！」开上一家。起叫至少几个由人数决定（两人 2 个，三人 3 个，四人 4 个）。叫数分两步：先上下调数量（往下到底是「开！」），OK 后再选点数（往下到底是「返回」）。1 点万能，有人叫过 1 之后（斋）1 只算自己。开盅后数清：叫中了罚开的人 1 分，没叫中罚叫的人 1 分；被罚的人下一局先叫，先罚满的人输。

**中途退出：** 对局中双击或长按上键都不会退出（防止翻叫数时误触）。按住 OK 2 秒暂停，选「回到封面」，再在封面双击上键。

音效（发牌、翻牌、摇盅、扣盅、开盅、获胜）都是实时合成的，跟随设置里的音量。

## 声音与设置

牌桌、跳一跳的本地音效使用 16 kHz 播放。跳一跳蓄力声采用 0.65 幅度和淡入淡出，切换声音有短过渡。界面 100% 音量仍给小扬声器保留输出余量；请根据环境调整。

设置包含音量、扬声器、亮度、休眠、麦克风增益、添加网络、Wi-Fi 开关、状态、电池、关闭屏幕和关机。USB 接入时保持待机屏幕亮起，手动关闭屏幕仍可使用。

## 排查

无法语音打开时，先确认能正常对话、屏幕识别文字与命令一致，并且当前在小智主页。固件不是完全离线语音识别。

对话重连时先核对 Wi-Fi 与服务器。需要报告固件问题时，请提供 Release 版本和去除私人内容的错误堆栈；不要上传 NVS、整片备份、账号令牌或完整私人对话。
