# NABO FM v1.0.1 · 体验更新

**v1.0.1 为基于封存 06r5 的部分验收体验版。** 用户主动提前结束剩余验收；本版不宣称全部 QA 或长播通过。实际发布 / 审核状态以 GitHub Release 和社区页面为准。

把 AI Passport 变成带 NABO DJ 动画的网络收音机：1,105 台内置目录、拼音首字母搜索、收藏与最近收听、定时关闭和北京时间待机小钟。

本次使用已刷入的**候选 06r5 精确应用**；发行打包只更新文档、源码绑定和校验信息，不重新编译已测试镜像。

## 本次变化

- 改善回到主页后再次收听时可能无声，以及退出电台后语音恢复的问题。
- 调整短时断流后的等待与声音过渡，让恢复播放更平缓。
- 改进连接失败或断网后的重试，减少反复启动播放。

## 实际验证范围

- **Build / Host PASS**：ESP-IDF 6.0.2 / ESP32-C3，16 脚本完整宿主套件通过。生命周期、碎片堆、网络和音频过渡替身测试不等同于实际网络或完整语音验收。
- **Flash / boot PASS（有界）**：应用区更新前完成新备份，写后全片读回确认精确应用及全部未写字节保留；启动 ELF 前缀匹配，未复现 06r4 的启动 timer 错误。NVS、PHY、资源和 files 保留；这是已配置设备上的应用更新，不是空白设备完整首装。
- **Device PARTIAL**：台 26 收齐 36 个完整窗口 / 180.422 秒，decoded/out 为 1，重缓冲和重连均为 0；用户确认当前声音“连续、清楚”。正式验收完成 2 / 5 轮 HOME→电台往返，共 6 个完整窗口 / 30.064 秒，decoded/out 均为 1；第三次 HOME 恢复有日志，第三轮电台尚未收齐窗口，不计完整往返。
- **完整验收由用户主动提前结束**：正式流程以 operator interruption 停止，没有把未运行阶段记为固件失败，也没有计为通过。三台各 600 秒、20 次受控切台均未完成；本次短测不能证明长时无卡顿、无缝切台或所有网络下稳定。首次台 26 诊断也曾被用户手动切到 27 中断，原报告保留，未计 180 秒通过。详见 [06r5 设备记录](../validation/radio-candidate06r5-device-2026-10-31.json)。
- **保留限制**：1,105 是目录数量，不保证全部台可播。AAC/HE-AAC、部分失效台源、强制弱网、恢复后的完整连续语音与完整首装仍未完成本轮实机验收。播放期间暂停小智语音，长按上键回主页后再对话，不支持边播边语音。

06r2 / 06r3 的播放失败与 06r4 的启动恢复失败保留在 [验证记录](VALIDATION.md)，没有用本次短测覆盖历史失败。构建与专项见 [06r5 Build / Host 记录](../validation/radio-candidate06r5-2026-10-31.json)。

## 发布附件与安装

v1.0.1 提供以下附件：

- `ai-passport-nabo-xiaozhi-radio-v1.0.1-full.bin`：社区/网页完整安装镜像，从 `0x0` 写入。**会清空配网、激活和 NVS 设置，刷完需重新配网/激活。**
- `ai-passport-nabo-xiaozhi-radio-v1.0.1.zip`：分区镜像、manifest、校验和、受保护的分区刷写工具、使用文档和第三方许可。
- `manifest.json`、`SHA256SUMS.txt`：最终源码提交、镜像身份和实际发布附件的校验值。ZIP 不能直接作为完整 BIN 写入。

已有设备希望保留数据，先读 [刷写说明](FLASHING.md)。只有 bootloader、分区和资源均确认匹配时，才具备专门校验的仅应用更新前提；历史 v1.0.0 设备不能据版本号直接推定匹配。普通包内 upgrade 工具写应用和资源，并核对 bootloader / 分区；不匹配时停止核对，不绕过检查。

仅适配 FoloToy AI Passport（ESP32-C3 / 8 MB）。本轮设备通过应用区升级，完整网页首装未实机验收。

## 第一次使用

1. 首次无网络记录会进入配网；换网用主页下键 → 工具 → 更多设置 → 添加网络。
2. 手机连接屏显的 `Xiaozhi-XXXX` 热点，浏览器打开 `http://192.168.4.1`，选择自己的 2.4 GHz Wi-Fi，输入密码点“连接”。网页显示“配置成功”且工牌联网后按工牌 OK 返回；失败核对密码重试，绑定按屏幕指引完成。
3. 主页下键 → 工具 → 网络电台；播放页上下换台，OK 播放/暂停、双击收藏、长按菜单。
4. 上键双击返回上一级，长按停止电台并回小智后再对话。重启可按保存状态续播。完整操作见 [使用指南](USER_GUIDE.md)。
