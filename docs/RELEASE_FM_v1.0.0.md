# NABO FM v1.0.0 · 首版体验固件

把 AI Passport 变成一台带 NABO DJ 动画的网络收音机：午夜琥珀界面、1,105 台内置目录、拼音首字母搜索、收藏与最近收听、定时关闭和待机时钟。

这是第一版公开体验固件，使用已实机运行的**候选 03 精确应用**，没有重编译或混入 04/05。独立收藏列表、收藏/待机设置重启保存、北京时间显示已验证；用户此前确认 03 音量增大且无爆音。MP3 48 / 44.1 / 32 / 22.05 kHz 已实际解码，回退后另观察约五分钟（含换台）未出现崩溃、连接/分配失败或输出停住。

## 已知限制

- **1,105 是内置目录数量，不代表全部台当前可播。** 桌面台源检查曾有 7 个 HTTP 404、8 个超时。
- AAC/HE-AAC 仍有内存/兼容问题；长时无卡顿、50 次实机切台和全部台逐项验收未完成，仍可能出现短时供音间隙。
- 播放时暂停小智语音；长按上键回主页后再对话，不支持边播边语音控制。
- 额外提高一档音量的 04/05 因实机问题没有发布。本版保留 03 的声音处理。
- 完整包只完成镜像、布局、校验和及空白数据区验证；没有在空白设备重新完整安装本次组合。

## 下载与安装

- `ai-passport-nabo-xiaozhi-radio-v1.0.0-full.bin`：社区/网页刷机工具使用的完整镜像，从 `0x0` 写入。**会清空配网、激活和用户设置，刷完需重新配网/激活。**
- `ai-passport-nabo-xiaozhi-radio-v1.0.0.zip`：四个分区镜像、manifest、校验和、保留数据的刷写工具、使用说明、字体许可和 Helix 对应源码。ZIP 不能当作完整 BIN 写到 `0x0`。
- `manifest.json`、`SHA256SUMS.txt`：对应源码提交、镜像身份和校验值。调试 ELF 保留本地，未作为社区固件上传。

仅适配 FoloToy AI Passport（ESP32-C3 / 8 MB）。已有设备要保留数据，先读 [刷写说明](FLASHING.md)；bootloader/分区检查不匹配时会停止，不要绕过或整片擦除。

## 第一次使用

1. 首次完整刷机后开机，按屏幕提示进入 Wi-Fi 配网；手机连接屏幕显示的工牌热点，再按提示地址打开配网页，选择可用的 **2.4 GHz Wi-Fi** 并保存。工牌联网后等待完成启动。
2. 若提示小智激活/绑定，按屏幕提示到小智控制台完成自己的设备绑定；不要向他人分享配网密码或绑定码。
3. NABO 主页按下键进入工具，选择“网络电台”；中键播放/暂停，上下键换台。
4. 双击中键收藏/取消；长按中键打开菜单，“收藏列表”单独查看已收藏电台。
5. “待机时钟”选择 1/3/5/10 分钟或关闭待机；“定时关闭”用于到时停止收听，两者不同。
6. 双击上键返回，长按上键停止电台并回小智主页。更多操作见 [使用指南](USER_GUIDE.md)。
